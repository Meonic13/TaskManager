## 📖 Описание

Приложение для управления задачами с возможностью установки приоритетов и автоматического планирования выполнения. Система использует алгоритм очереди с приоритетом на основе **бинарной кучи (Max Heap)** для эффективного распределения задач по степени важности.

### ✨ Возможности

- ➕ Добавление задач с указанием названия, приоритета и времени выполнения
- 🎊 Четыре уровня приоритета: **Low**, **Medium**, **High**, **Critical**
- 📊 Автоматическое планирование задач по приоритету
- ⏱️ Визуализация расписания с временными интервалами (время начала и окончания)
- 🧪 Тестирование производительности на больших объёмах данных (до 10 000 задач)
- ✅ Модульное тестирование (24 теста, покрытие >60%)

## 🔧 Реализованные алгоритмы

### 1. Очередь с приоритетом на основе Max Heap

**Принцип работы:**
- **Бинарная куча** — полное бинарное дерево, где каждый родительский узел больше или равен дочерним
- Хранится в массиве: для индекса `i` левый потомок `2i+1`, правый `2i+2`, родитель `(i-1)/2`
- **Вставка (Enqueue)**: O(log n) — добавление в конец массива + подъём вверх (SiftUp)
- **Извлечение (Dequeue)**: O(log n) — извлечение корня (максимума) + спуск вниз (SiftDown)
- **Получение максимума (Peek)**: O(1) — просто возвращаем корень

**Ключевые методы:**
```csharp
public void Enqueue(TaskItem item)           // Добавление задачи в очередь
public TaskItem Dequeue()                    // Извлечение задачи с наивысшим приоритетом
public TaskItem Peek()                       // Просмотр задачи без удаления
private void SiftUp(int index)               // Подъём элемента вверх
private void SiftDown(int index)             // Спуск элемента вниз
Вход: [Low, Critical, High, Medium]
После построения кучи: [Critical, High, Medium, Low]
Dequeue() → Critical
Dequeue() → High
Dequeue() → Medium
Dequeue() → Low
```
2. Алгоритм планирования задач
Принцип работы:
Непреemptive планирование (без прерывания) — задача выполняется до конца
Задачи выполняются последовательно в порядке убывания приоритета
Для каждой задачи рассчитывается время начала и окончания
Использует очередь с приоритетом для сортировки задач
Сложность: O(n log n) — n вставок в кучу + n извлечений
Пример работы:
Входные задачи:
  - "Срочный звонок" (Critical, 15 мин)
  - "Сделать ДЗ" (High, 60 мин)
  - "Почитать книгу" (Low, 30 мин)

Расписание:
  1. [Critical] Срочный звонок        0-15 мин
  2. [High]       Сделать ДЗ          15-75 мин
  3. [Low]        Почитать книгу      75-105 мин
